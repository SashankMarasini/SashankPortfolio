PROJECTS

Intemporelle

Intemporelle Watch is a modern, responsive website developed as part of a group project in college. The aim was to create a professional online presence for a luxury watch brand, focusing on both visual appeal and user experience.As a core member of the team, I was involved in designing the layout and building the front-end using HTML, CSS, and JavaScript. I worked on structuring the content, styling for responsiveness across devices, and adding interactive elements like hover effects and smooth scrolling. The website includes sections such as a homepage, product gallery, and brand highlights to bring the concept to life.This project not only strengthened my technical skills in front-end web development but also taught me the value of collaboration, design consistency, and building websites with real-world usability in mind.





We Care

We Care is a user-friendly billing and inventory management system I developed using Python, specifically tailored for a beauty store environment. The goal was to simplify and systematize day-to-day tasks like managing stock, organizing product details, and generating invoices during customer purchases. The system neatly displays available products, updates stock levels in real-time, and automatically calculates totals during checkout — making the billing process smooth and accurate. I structured the project using multiple Python files to keep the code modular and manageable, covering operations like reading and writing files, displaying products, and handling transactions. This project not only sharpened my programming skills but also gave me practical experience in solving real-life problems through code. It helped me understand how Python can be used to build efficient systems that are both functional and easy to use.









Gym Management System

The Gym Management System is a Java project I created to manage gym members and their memberships in a systematic and organized way. The main goal was to build a user-friendly system that could store and display important details like member names, contact info, membership plans, payment status, and more — all in one place. While developing the system, I made full use of the core object-oriented principles in Java. I used Encapsulation to keep member data secure and properly structured, Inheritance to manage different types of members such as Regular and Premium, and Polymorphism to allow the system to handle specific actions depending on the member type. I also used Abstraction to hide complex internal code and keep the interface clean and easy to interact with. This project really helped me connect the theory of Java OOP concepts to a real-world scenario. It gave me a better understanding of how to write clean, modular code while solving practical problems. It was a great experience that improved both my programming skills and logical thinking.
